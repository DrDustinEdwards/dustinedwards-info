# dustinedwards.info: build history

One entry per decision that shaped the site as it stands on 2026-09-24, in date order. Abandoned directions, reversed rulings and superseded designs are left out on purpose. Entries tagged **[post]** would make a good "how I built this" blog post.

PR links point at https://github.com/DrDustinEdwards/dustinedwards-info/pull/N. Commit hashes are given where the work predates pull requests. "vol N" is the Capsid decisions volume the entry came from.

## July 2026: the foundations

- **2026-07-06. Admin sign-in is Better Auth with Google, for one admin.** One React Router middleware guards everything under /admin for a single ADMIN_EMAIL. The real wrangler.jsonc was scrubbed from git history, and only wrangler.jsonc.example is tracked, so account ids never land in the repo.
- **2026-07-26. Static images live in public/, structured data in typed files.** Committed images such as the roster photos add nothing to the Worker bundle, and R2 is kept for uploaded media. The roster and publications live under app/data/ rather than as posts, so their structure survives. (vol 1)
- **2026-07-27. A paper's PDF supplies one fact, its DOI.** Every other field comes from the registry that minted the DOI (Crossref, DataCite, Europe PMC for abstracts). Candidates are never accepted from an author-name search, because OpenAlex returned 43 works for the author filter and 7 were by other people, and no abstract is ever generated. The data is CSL-JSON, the format Zotero, Pandoc and the CV share, and app/data/publications.ts is generated from it. [PR #2](https://github.com/DrDustinEdwards/dustinedwards-info/pull/2). (vol 1) **[post]**
- **2026-07-27. DOIs are stored as deposited and compared case-insensitively; each paper shows its own citation count, with no site total.** Raw comparisons had silently dropped records. Scholar said 339 citations and OpenAlex 257, both true, so a total would need a methodology note. Counts are cached in KV for 7 days and refreshed after the response, so OpenAlex never slows a page. (vol 1)
- **2026-07-27. Filter state lives in the URL and filtering happens on the server.** Crawlers get the filtered list and the filter works without script. (vol 1)
- **2026-07-27. Markdown in git is the source; D1 holds the rendered copy.** Posts are markdown in content/posts/, validated by zod, rendered into D1, which serves every read and the FTS5 search. Two measurements from that day still shape the build: `wrangler d1 export` fails on FTS5 tables, so backups are per table, and `DELETE FROM` corrupts an FTS table, so the repair is `('rebuild')`. [PR #4](https://github.com/DrDustinEdwards/dustinedwards-info/pull/4). **[post]**
- **2026-07-28. One render pipeline runs in both Node and the Worker.** app/lib/content/pipeline.mjs renders the build and the editor preview alike, so a preview matches what publishes. Highlighting uses shiki core with a language allowlist (full shiki added 14 MB to the Worker) and the oniguruma engine, because the JavaScript regex engine colored the same token three ways across runs; the WASM is injected precompiled because Workers refuse to compile it at runtime. content/ is pinned to LF because Windows line endings changed published bytes. [PR #5](https://github.com/DrDustinEdwards/dustinedwards-info/pull/5). **[post]**
- **2026-07-28. The editor has exactly one write: an atomic commit through the GitHub Git Data API.** Then a sync to D1; direct row writes are banned. The zod checks run on the server because API commits skip local hooks, and a save is refused if the branch head moved. [PR #5](https://github.com/DrDustinEdwards/dustinedwards-info/pull/5). (vol 1)
- **2026-07-28. Every public blog feature is rendered on the server.** Table of contents, footnotes, series, related posts, agent action links and line highlighting all arrive as HTML. [PR #6](https://github.com/DrDustinEdwards/dustinedwards-info/pull/6).
- **2026-07-28. Social cards are built in Node and stored in R2 by a hash of what they draw.** satori and resvg run at build time, not in the Worker, for size and WASM cost. The admin gained version history, where a restore lands as a new commit. [PR #7](https://github.com/DrDustinEdwards/dustinedwards-info/pull/7).
- **2026-07-28. Search is one record per section, in two FTS5 indexes merged by rank fusion.** An identity index (unicode61) and a prose index (porter) were measured to fail differently, so their lists are merged by reciprocal rank fusion at k=60. /search is a server-rendered GET form that also answers as JSON, with a browse path for filter-only queries. [PR #8](https://github.com/DrDustinEdwards/dustinedwards-info/pull/8), [PR #9](https://github.com/DrDustinEdwards/dustinedwards-info/pull/9). **[post]**
- **2026-07-28. Ask is managed AI Search, a removable layer above keyword search.** No self-managed vector store. No keyword query waits on Ask, and with the binding removed keyword output was byte-identical. Both stay because they fail on opposite questions: keyword search found 2 things AI missed and AI found 3 keyword search missed. Ask indexes one item per section, and the item key is the citation. [PR #10](https://github.com/DrDustinEdwards/dustinedwards-info/pull/10). (vol 1) **[post]**
- **2026-07-28. Ask's rate limit runs in a Durable Object with synchronous SQLite.** The async rate-limit binding and an async Durable Object both let extra requests through when measured. The order is fixed: per-IP limit, then the answer cache, then the daily ceiling, so a cache hit costs nothing. [PR #11](https://github.com/DrDustinEdwards/dustinedwards-info/pull/11). **[post]**
- **2026-07-28. The theme is decided on the server.** A form POST to /theme sets a cookie and the server writes data-theme into the first byte, so there is no flash by design; "system" is the absence of the attribute. [PR #12](https://github.com/DrDustinEdwards/dustinedwards-info/pull/12).
- **2026-07-28 to 07-30. Agents publish through the editor's own write path, and a first publish is reserved for Dustin.** A token-protected operator API calls the same savePost; the server reads first_published only from the committed file, so an agent cannot claim it. The MCP front end is a separate Worker in the dustinedwards-mcp repo (OAuth 2.1) because it would have added about 205 KB gzip to the site Worker. [PR #13](https://github.com/DrDustinEdwards/dustinedwards-info/pull/13). **[post]**
- **2026-07-29. Drafts leaked into Ask, so every public object derived from a post passes the visibility check.** The AI index cannot filter by status at query time; uploads now check publiclyVisible, unpublishing removes a post's items, and list calls page through everything. The rule covers HTML, feeds, search records, Ask answers and social cards. **[post]**
- **2026-07-29. Mainline until the domain move.** The main checkout commits straight to main and the checks are the review; other actors land by PR from worktrees (see 2026-09-15). (workflow-mainline.md)
- **2026-07-30. Charts and diagrams render at build time, with required alt text.** `:::chart` renders Observable Plot through linkedom to static SVG; `:::diagram` renders Mermaid into a light and a dark SVG, because mermaid rejects CSS variables and a var() fill paints black inside an img. Unknown directives fail the build. Commits c8c4ba0 to f3a7906, cee22f5. **[post]**

## August 2026: hardening

- **2026-08-01. URL protocols are allowlisted as the last render step.** It runs after control characters and entities are cleaned, and a blocked link is shown as its source text rather than a link with an empty href. Frontmatter URLs pass the same allowlist. Commits 8051b2b, 5dba09d.
- **2026-08-01. The admin editor body is CodeMirror 6 over a real textarea.** The form still works without it, and the preview renders through the shared pipeline in a sandboxed iframe; all 12 posts rendered byte-identical to what publishes.
- **2026-08-02. The media index lives in D1, built from R2 events through a Queue.** R2 stays the source of truth and wins every conflict; there is never a dual write. The principle: an index is legitimate when it can be reconciled against its source. (vol 2) **[post]**
- **2026-08-02. Media keys are content-addressed, with the image size in the key.** A truncated sha256 means a draft's images cannot be guessed from its slug, and `<sha16>-<w>x<h>.<ext>` makes both writers agree by construction. Thumbnails are WebP only: AVIF saved 1.2 percent and per-request format choice broke the manual cache key. (vol 2)
- **2026-08-02. Workers Cache is on, and a response that declares nothing is stamped private, no-store.** The cache key ignores cookies, so without the stamp an admin page would have been cached for two hours. (vol 2)
- **2026-08-02. Terraform rejected; RECOVERY.md written instead.** A third declaration of the bindings would drift. Measured: the migrations reproduce the live schema, 37 of 37 objects. (infrastructure-recovery.md)
- **2026-08-02. The phage roster returned at /phage-discovery.** It is the legacy URL search engines already index, so the cutover replaces the page instead of redirecting it. Commit 9c75de6.
- **2026-08-07. Checks verify the working tree, so nothing deploys from a dirty tree.** (vol 2)
- **2026-08-10. Every posts reader applies publiclyVisible(), and every migration is hashed against a manifest.** The drafts-never-public and migrations checks both survive the 2026-09-24 check cut. (vols 3 and 4)
- **2026-08-12. Analytics is Cloudflare Analytics Engine: first-party, server-side, no client script, no visitor id.** Web Analytics was rejected because its beacon breaks the strict CSP; invocation logs are off so IPs and cookies are not stored. (vol 5) **[post]**
- **2026-08-14. The admin reports origin requests with SUM(_sample_interval), never COUNT().** A probe proved cached hits never reach the Worker, so the panel is labeled origin requests, not traffic. **[post]**
- **2026-08-14 to 08-31. /projects and /playground.** One product is one card, nothing without a public surface; each metric carries a date or a derivation computed by one function the route and the check share. The playground reports WCAG 2.2 contrast and labels APCA experimental. (decisions.md, vol 11)
- **2026-08-15. Draft preview links are KV tokens at a top-level /preview route.** A reviewer without cookies can never be served from, or write into, the public cache; tokens are revoked on publish and redacted before the analytics write. Commit 4405f7b.
- **2026-08-15. Media trash hides a file but never takes its URL down.** Duplicates are exact content-hash matches, and the UI says "no reference found," never "unused."
- **2026-08-15. Ship refuses to deploy while remote D1 has pending migrations.** A green deploy had served a 500 because a migration was not applied.
- **2026-08-16. Hashed assets are immutable for a year.** Workers Assets defaults to max-age=0, must-revalidate; public/_headers fixed it. Measured: 14 revalidations per page load before, 9 of 10 assets from cache after.
- **2026-08-16. Destructive actions confirm on the server.** A script-only prompt() had been emptying trash with no confirmation; now an unconfirmed destructive POST renders a confirmation step, and operators cannot delete at all.
- **2026-08-16. The CSP is enforced with a per-response nonce and strict-dynamic.** 'self' was proven unworkable, and the tradeoff with shared caching is explained on /colophon. **[post]**
- **2026-08-16. Ask is POST-only, uploads accept six image types, and SVG is served as a download.** The CSP report endpoint reads a capped body.
- **2026-08-19. CI runs a derived list of checks on a clean checkout, and the browser check runs against a preview build.** Its first run found 8 real defects, including sideways scrolling on every page at 320px. Commit e917812.
- **2026-08-19. A page number past the end redirects to the last page.** Heading permalinks are reachable by keyboard and visible on touch.
- **2026-08-21. Fonts are self-hosted and content-hashed.** Each navigation had spent a round trip on Google Fonts; CSP font-src and style-src dropped to 'self'. This is the start of the first-visit fonts story (2026-09-23). (vol 7)
- **2026-08-21. The 9,269-line stylesheet was split by surface into app/styles/.** The built output was proven byte-identical. (vol 7)
- **2026-08-22. An audit found three security holes with one cause.** An unauthenticated media delete, a draft-title leak and brute-forceable preview links all came from `context.get()` returning undefined, so every "no user, skip" guard passed; four more routes had the same pattern. (vol 7)
- **2026-08-23. Headers and limits derived from what the site uses.** Permissions-Policy is derived from real use, sign-in callbacks are rate limited per IP, Ask's daily cap is paced across the day, plaintext HTTP gets a no-store 301 (the cached HTTPS page, nonce included, had been served over plaintext), and login became a real form. Commit e7ede14. (vol 8)
- **2026-08-23. Ship refuses unless CI succeeded on the exact commit, with no override flag.** Commit b65251c6. (vol 8)
- **2026-08-24. Ask is synced as ship's last step.** A git-authored change no longer leaves Ask stale until someone clicks. Commit 2330e62. (vol 8)
- **2026-08-24. Money paths refuse cheapest-first: origin, rate, cache, budget, model.** A foreign Origin is refused, an absent one allowed because a scriptless form sends none. (vol 8)
- **2026-08-24. Chores are defects.** Anything left in Dustin's hands that is not a decision is automated: the media index syncs at ship, health repairs known drift through the operator door, and a least-privilege smoke token lets the browser checks exercise the admin. Commits ea479c8, c445f4e. (vol 8) **[post]**
- **2026-08-25. Deploys run from a GitHub Actions button that runs the full ship script.** The admin overview was rewired to real instruments. Commit 98d30c7. (vol 8)
- **2026-08-26. Rendered HTML left git.** Git holds markdown only; the 648 KB posts.json is gone, `renderAndWrite` is the only way to write a rendered row, rows carry source_blob_sha and render_hash, and ship reports any render drift between Worker and Node. First ship: 0 drift across 12 posts. Commits 6b6460f, f7ae0d9. (vol 9) **[post]**
- **2026-08-26. The public pages stopped hydrating React.** Hydration is opt-in per route; enhancements are prebuilt bundles in app/enhance/ loaded as nonced module scripts. Measured: about 95 KB brotli of framework script per article went to zero. Commit cba0263. **[post]**
- **2026-08-26. Every body image links to its original.** The lightbox attaches to that link, so without script a click still opens the file. Commit fdb6eb3.
- **2026-08-27. Page weight cut.** Tailwind left the public bundle, CSS and scripts load per route, the search palette loads on demand, and the home health tile reads a KV snapshot. Home LCP went from 5,192 to 2,024 ms. Commits 0da4a9b, bdb7632. (vol 10) **[post]**
- **2026-08-27. Ask hardened, one origin check, accessible lightbox, /privacy.** Ask never caches an answer built from zero sources; one origin check guards admin actions, /theme and Ask; the lightbox is a native dialog. Commit 50233cd. (vol 10)
- **2026-08-27 to 08-28. The blink between pages had three causes.** A server-set color-scheme meta tag, `@view-transition { navigation: none }` (Chrome's crossfade stacked both pages for 214 to 259 ms) and a speculation rule that prefetches instead of prerendering. Every headless tool was blind to it; only screen capture and Dustin's eyes saw it. Commit 657a960. (vol 10) **[post]**
- **2026-08-28. Dependency and type hygiene.** Runtime packages moved to dependencies, build tools pinned exactly, oxlint in CI, noUncheckedIndexedAccess on serving code, full post bodies in RSS. Commit d97b93a.
- **2026-08-29. A separate watchdog Worker watches the site.** GitHub scheduled runs had decayed from 38 a day to 2. The watchdog runs every 15 minutes, reaches the site through a service binding (error 1042 blocks Worker-to-Worker HTTPS on workers.dev), repairs through the operator door and emails when repair fails. Commit 6f576d8. **[post]**
- **2026-08-29. A Worker test layer runs offline in workerd.** Loaders, actions, D1, KV, R2, Durable Objects and the Cache API, with a named test for every defect that only showed in production. Commit b2bffc3.
- **2026-08-29. Social cards stay out of the media library.** Code creates and removes them, and a guard refuses to delete live cards. (vol 11)
- **2026-08-30. The blog shows what it stores.** Two audits found fields stored and never shown (featured, series, further reading, cover, description, tags), so frontmatter controls came before distribution work. (vol 11)
