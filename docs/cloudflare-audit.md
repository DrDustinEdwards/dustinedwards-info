## Changes in this PR

1. `app/lib/bearer.server.ts`: `timingSafeEqual` replaces the loop.
2. `wrangler.jsonc.example`: `head_sampling_rate: 1` stated. **The real, gitignored `wrangler.jsonc` needs the same line before the next deploy; only Dustin's checkout has it.**
3. `test/cloudflare-practices.test.mjs`: fails if the loop returns or the sampling rate is removed. Putting the loop back was run and the test went red.

## DECIDE points

1. **Type-aware no-floating-promises.** oxlint's rule needs the type-aware add-on, and its first run will report existing sites. Recommendation: yes, in its own PR, fixing what it finds and allowlisting nothing.
2. **Octokit for the editor's GitHub calls.** Recommendation: no. The conflict guard on the Git Data API is the reason for raw `fetch`, and Octokit adds weight for no change in behaviour.
3. **Webmention verification through a Queue.** Recommendation: leave it. It never throws and a failure leaves a visible `unverified` row.
