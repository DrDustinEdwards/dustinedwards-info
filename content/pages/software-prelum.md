## The publishing library

Prelum turns markdown into pages, feeds, sitemaps, search records, llms.txt and each page's structured data. It is shared by Dustin Edwards's sites, so each one publishes the same way. It is MIT licensed.

## Source

[DrDustinEdwards/prelum on GitHub](https://github.com/DrDustinEdwards/prelum). The [colophon](/colophon) describes how this site uses it.
